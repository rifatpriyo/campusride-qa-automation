# BUG-002 Confirmed fare changes after booking

**Controlled defect in local demo application**

| Field | Value |
| --- | --- |
| Bug ID | BUG-002 |
| Related requirement | REQ-006 Confirmed fare |
| Related manual test | TC-016 Block quote misuse and preserve the fare after acceptance |
| Severity | S2 High. The confirmed amount can diverge from the price the passenger accepted. |
| Priority | P1 Current cycle. Passengers and riders need to be able to rely on the quoted fare. |

## Environment

CampusRide QA Lab Phase 3 on Windows, Python 3.11.5, pytest 9.2.0, and temporary SQLite. The observed failure used FastAPI TestClient with a loopback ASGI address and `DEMO_BUG_MODE=true`.

## Preconditions

Sign in as Mira against a fresh demo seed. Use a new quote-backed booking. The ride must be requested and unassigned when attempting the fare edit.

## Reproduction steps

1. Start the [local lab](../docs/DEFECT-INVESTIGATION.md#start-a-local-investigation) with defect mode enabled.
2. As Mira, call `POST /api/rides/quote` with pickup `north_gate`, destination `residence_quad`, and preference `regular`. Record the BDT 80 quote and its ID.
3. Call `POST /api/rides` with that `quote_id` and record the new ride ID and fare.
4. Call `PATCH /api/rides/{ride_id}/fare` with `{"fare_bdt":5}` using Mira's session.
5. Read `GET /api/rides/{ride_id}` in a separate request and compare the fare with the quote.

## Expected result

The fare-edit route is absent in normal mode and returns HTTP `404`. The follow-up read shows BDT 80.

## Actual result

The booking initially showed BDT 80. The edit returned HTTP `200`, and the follow-up read showed BDT 5.

## Confirmed root cause

The lab router exposes a post-booking update that writes the supplied amount to `Ride.fare_bdt`. The write replaces the price copied from the quote. [Lab fare route](../app/bug_lab.py)

## Recommended fix

Keep confirmed fare assignment in the booking transaction. Remove the post-booking fare writer from the application path and verify that a later read still matches the booked quote.

## Evidence references

See `test_bug_002_preserves_the_booked_fare` in the [defect-mode output](../reports/bug-lab/03-defect-mode.txt) and [corrected-mode output](../reports/bug-lab/04-corrected-mode.txt).

## Verification status

Reproduced with defect mode on. With the mode off, the same test verified HTTP `404` and the original BDT 80 fare on readback.
